# MINGLO

A playful culture-learning website built with HTML, CSS, JavaScript, and Three.js.

[Visit MINGLO](https://kin-culture-journey.xsun18469001.chatgpt.site)

## Run locally

From the repository folder, run:

```sh
python3 -m http.server 4173
```

Then open http://localhost:4173.

## Project structure

- `index.html` — navigation and application entry
- `app.js` — pages, challenges, cards, and community interactions
- `style.css` — typography, colors, layouts, and animation
- `globe3d.js` — draggable 3D globe and landmarks
- `assets/` — illustrations, icons, and bundled Three.js modules

Prototype contributions and progress are stored in the visitor's browser, not a shared backend.
